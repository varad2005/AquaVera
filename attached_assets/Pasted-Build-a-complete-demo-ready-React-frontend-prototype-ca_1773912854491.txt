Build a complete, demo-ready React frontend prototype called "AquaVera" — an AI-powered irrigation water billing and crop verification platform for Indian farmers. No backend needed. Use only React with local component state and mock data. Use Tailwind CSS for styling. Use React Router for navigation. Use lucide-react for all icons — no emoji anywhere. All logic is simulated on the frontend.

## BILLING RATES — EXACT FROM GOVERNMENT TARIFF DOCUMENT

### Table 1: Volumetric Rates for Flow Irrigation (Paise/cum = Rs/1000L)
These rates are for REGISTERED WATER USER ASSOCIATIONS (beneficiaryType === 'wua'):
- Kharif: Rs 5.50/cum | Rabi: Rs 11.00/cum | Hot Weather: Rs 16.50/cum
For INDIVIDUAL BENEFICIARY (beneficiaryType === 'individual'):
- Kharif: Rs 7.00/cum | Rabi: Rs 14.00/cum | Hot Weather: Rs 21.00/cum

### Table 2: Bulk Water Tariff for Private Lift Irrigation (Paise/cum)
These apply when waterSource is set. Use these rates based on waterSource key:
- assuredMajor: Kharif 6.50, Rabi 13.00, HotWeather 19.50
- assuredMedium: Kharif 5.00, Rabi 10.00, HotWeather 15.00
- regulatedLoss: Kharif 5.00, Rabi 10.00, HotWeather 15.00
- partlyRegulated: Kharif 2.50, Rabi 5.00, HotWeather 7.50
- userMaintained: Kharif 0.80, Rabi 1.60, HotWeather 2.40

### Table 3: Area-based Bulk Water Tariff for Flow Irrigation (Rs/Ha)
These are the AREA-BASED rates per hectare per season:
- foodGrains: Kharif 600, Rabi 1200, HotWeather 1800
- sugarcane: Kharif 1890, Rabi 3780, HotWeather 5670
- banana: Kharif 1890, Rabi 3780, HotWeather 5670 (same as sugarcane — Cash Crops)
- cotton: Kharif 810, Rabi 1620, HotWeather 2430
- horticulture: Kharif 1422, Rabi 2844, HotWeather 4266

### Billing Logic Implementation in /utils/billing.js:
```js
// Table 3: Area-based rates Rs/Ha
export const AREA_RATES = {
  foodGrains: { kharif: 600, rabi: 1200, hotWeather: 1800 },
  sugarcane:  { kharif: 1890, rabi: 3780, hotWeather: 5670 },
  banana:     { kharif: 1890, rabi: 3780, hotWeather: 5670 },
  cotton:     { kharif: 810, rabi: 1620, hotWeather: 2430 },
  horticulture: { kharif: 1422, rabi: 2844, hotWeather: 4266 }
};

// Table 1: Volumetric rates Rs/cum for flow irrigation
export const VOLUMETRIC_RATES_WUA = { kharif: 5.50, rabi: 11.00, hotWeather: 16.50 };
export const VOLUMETRIC_RATES_INDIVIDUAL = { kharif: 7.00, rabi: 14.00, hotWeather: 21.00 };

// Table 2: Bulk lift irrigation rates Rs/cum
export const LIFT_RATES = {
  assuredMajor:     { kharif: 6.50, rabi: 13.00, hotWeather: 19.50 },
  assuredMedium:    { kharif: 5.00, rabi: 10.00, hotWeather: 15.00 },
  regulatedLoss:    { kharif: 5.00, rabi: 10.00, hotWeather: 15.00 },
  partlyRegulated:  { kharif: 2.50, rabi: 5.00,  hotWeather: 7.50  },
  userMaintained:   { kharif: 0.80, rabi: 1.60,  hotWeather: 2.40  }
};

// Primary billing function — uses Table 3 area-based rates
// Bill = Rate (Rs/Ha) * landArea (Ha)
// Duration is informational only for area-based billing (one rate per season regardless)
export function calculateAreaBill(cropKey, seasonKey, landArea) {
  const cropRates = AREA_RATES[cropKey];
  if (!cropRates) return 0;
  const rate = cropRates[seasonKey] || 0;
  return parseFloat((rate * Number(landArea)).toFixed(2));
}

// Returns the rate per hectare for display
export function getAreaRate(cropKey, seasonKey) {
  return AREA_RATES[cropKey]?.[seasonKey] || 0;
}

export function formatCurrency(amount) {
  return new Intl.NumberFormat('en-IN', {
    style: 'currency',
    currency: 'INR',
    minimumFractionDigits: 2
  }).format(amount);
}
```

Display in bill preview:
- Show: Rate Rs [getAreaRate(crop, season)] / hectare
- Show: Land Area: [landArea] hectares
- Show: Estimated Bill = formatCurrency(calculateAreaBill(crop, season, landArea))
